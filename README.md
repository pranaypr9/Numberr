# For Anishika 🌷

A small, mobile-friendly animated page with falling flowers and a message reveal button.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` (or upload the ZIP and extract it first).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

No build tools or dependencies are required.
